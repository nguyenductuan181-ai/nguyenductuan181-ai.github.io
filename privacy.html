Privacy Policy

Effective Date: August 15, 2026

Google API Policy Compliant
Workspace Automation Suite ("the Application") is an executive productivity and digital workspace management tool developed by Nguyen Duc Tuan. This Privacy Policy outlines our transparent practices regarding data collection, usage, and security in strict compliance with the Google API Services User Data Policy.

1. Google Workspace Data We Access

The Application requests permission to access user data only when explicitly authorized by the account owner via Google OAuth 2.0. We request the following specific scopes:

  • Google Photos (photoslibrary.readonly, photoslibrary): Access to list albums and view media metadata (creation timestamp, dimensions, filenames) solely to index personal photo libraries and verify automated local backup integrity.
  • Google Drive (drive): Access to create dedicated archive folders, upload backup files, and synchronize personal structured documents.
  • Google Sheets & Docs: Access to write operational summary logs, master index tables, and structured data reports.
  • Gmail (gmail.readonly, gmail.send): Access to monitor system notifications and send executive status reports exclusively to authorized personal email addresses.
  • Google Calendar: Access to manage deadlines and sync operational event reminders.

2. Purpose and Limitation of Data Use

All Google user data accessed is strictly utilized to provide requested workspace automation features directly to the account owner. Specifically:

  • No Commercial Data Sharing: We NEVER sell, rent, lease, or monetize any Google user data or media content to third parties, advertisers, or external data brokers.
  • No Third-Party AI Training: Google user data and media are NEVER used to train, retrain, or improve generalized artificial intelligence or machine learning models.
  • No Human Viewing: No human (developer or third party) reads or accesses raw user files, emails, or personal photos unless explicitly instructed by the user for technical debugging.
  • Local & Encrypted Execution: All OAuth tokens and operational cache are stored securely in encrypted storage on the user's private dedicated instance with restricted access controls.

3. Compliance with Google Limited Use Requirements

Workspace Automation Suite strictly adheres to the Google API Services User Data Policy, including the Limited Use requirements:

The Application's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4. Data Retention, Revocation, and Deletion

Users retain 100% control over their data at all times:

  • Instant Revocation: You can revoke access immediately at any time via the Google Account Permissions dashboard.
  • Permanent Deletion: Upon access revocation, all cached tokens, local indexes, and temporary metadata are permanently purged from the system.
