Workspace Automation Suite

An executive management utility designed to organize personal archives, automate media indexing, and synchronize structured workspace files across Google Workspace services.

1. Application Identity and Purpose

Application Name: Workspace Automation Suite

Developer & Owner: Nguyen Duc Tuan (nguyenductuan181@gmail.com)

Purpose of Application: Workspace Automation Suite is a personal productivity application created to eliminate manual, repetitive administrative tasks for the account owner. The application interacts with authorized Google services via OAuth 2.0 to automate local file archiving, catalog personal media assets, and generate structured operational summaries.

2. Specific Google Data Requested & Why

The application explicitly requests access to the following Google Workspace user data strictly for user-requested operations:

Google Photos Access

Reads photo metadata (timestamps, filenames, album names) to verify backup completeness and build local structured photo catalogs.

Google Drive Archiving

Creates folders and organizes authorized workspace files, documents, and historical backups automatically.

Google Sheets & Docs

Exports operational summaries, index tables, and structured productivity logs directly into Google Sheets.

Gmail & Calendar

Monitors system status notifications and sends operational status summaries to the authorized account owner.

3. Privacy, Data Protection, and Limited Use

Workspace Automation Suite adheres strictly to the Google API Services User Data Policy, including the Limited Use requirements:

  • No Commercial Data Sale: We never sell, rent, or transfer user data to third parties, advertising platforms, or data brokers.
  • No AI Model Training: Google user data is strictly prohibited from being used to train generalized artificial intelligence or machine learning models.
  • No Human Access: No person reads or views raw user files, emails, or photos. All data processing occurs via encrypted local scripts.
  • Revocation at Any Time: Users can revoke access instantly via the Google Account Permissions console.
